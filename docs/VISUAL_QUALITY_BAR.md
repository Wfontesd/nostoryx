# Visual Quality Bar

NOSTORYX should use references as measurable constraints, not as licenses to copy assets or layouts.

## Reference roles

- **Soul's Remnant** — small-scale 2D online-world structure and readable side-scrolling MMO presentation.
- **MapleStory** — spatial readability, zone identity, persistent RPG HUD/content vocabulary.
- **Elsword** — action readability, attack silhouettes, hit feedback, skill presentation and combat energy.

The Dev Labs concept image in `docs/references/dev-labs-concept.jpg` is an original internal reference generated specifically for this repository. It establishes the desired idea of isolated tools surrounding a real playable viewport; it is not a production screenshot.

## Acceptance rule

For visual features, "works" is necessary but not sufficient. A screenshot or short capture of the real build must be compared against the chosen quality bar. The next iteration should focus on the largest visible gap.
